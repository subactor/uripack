# Changelog

## 0.1.0a1 — 2026-09-08

Pierwszy działający zakres: inwentaryzacja wszystkich korzeni mapy, discovery
paczek Python/npm, własny zamknięty DSL, deterministyczny plan, wielowarstwowa
nieusuwająca ekstrakcja, zewnętrzny transport Guard, dispatch rejestrowanych
narzędzi, weryfikacja integralności, SDK TypeScript i testowe E2E obu języków.
Natywne integracje Subactor i produkcyjny cutover pozostają niezweryfikowane.
