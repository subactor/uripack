# UPK-LEASE-001

Konflikt właściciela lub istniejący cel.

Zachowaj obcy stan; ustal właściciela przez kontroler. Nie kasuj locka jako automatycznej naprawy.

Weryfikacja: ponów tylko bezskutkowy odczyt właściwego stanu i sprawdź plan, zakres oraz dowody. Nie obchodź Guard ani nie usuwaj obcej pracy.
